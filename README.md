# Sojourner

Sojourner is a static essay collection about life, thinking, and shared
experience. It is designed to run directly on GitHub Pages from the repository
root.

## Files

- `index.html` contains the page structure.
- `styles.css` contains the responsive editorial layout.
- `script.js` contains the article data, search, filtering, and reader state.
- `assets/sojourner-table.png` is the generated feature image used by the site.

## Local preview

Open `index.html` in a browser, or serve the folder with any static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
